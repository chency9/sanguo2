# 五分队、军令执行与 AI 分批推进（2026-11-18）

本轮把新战斗的“前军/后军/主将 + 三种动作”适配升级为原版分队命令槽和十种士兵移动分支。AI 的原版评分现在接入对应分队执行逻辑；全军冲锋只改变士兵军令，主将有独立命令。**这是军令函数的对照验收，尚不是原版完整战斗或界面一比一验收。**

## 证据与范围

基准 EXE SHA256：`1098558aaea96ae552753df786a8d3910df08fda11c8219dfa133ca001d8e419`。

| 地址 | 本轮核实并接入 |

原版普通部署仍为五个士兵分队，保存编号 1–5；主将为 0，6–7 为预留槽。Web 显示原有的粗分组字段以兼容旧档，逻辑使用独立 `nativeDivision`，不再把 3、4、5 合并成前军来执行新命令。

相邻研究项目的 `tools/native_command_oracle.py` 在 Unicorn 中运行固定指纹 EXE；移动入口钩子只记录方向和权重表地址，不替换命令、移动、占格或随机函数。对照输出保存在研究目录 `evidence/ai/native-command-vectors.json`，核心测试副本在 `packages/core/fixtures/native-command-vectors.json`。

```powershell
# 在 web-port-research 目录执行
.\.venv-ai\Scripts\python.exe tools/native_command_oracle.py
```

共 **1,080 组原机器码样本**：672 组士兵/主将命令移动、120 组命令槽写入、288 组 AI 推进。移动覆盖双朝向、六种纵向位置、横向边界、阻挡、目标存亡及原随机状态，逐项比对所选配置、目标格、速度、朝向、标志和随机数。AI 覆盖九阵、五个分队是否已推进的 32 种组合，包含不下新令但仍消耗随机数的分支。

新增六张原始移动配置表取自 `0x48E5C8`、`0x48E658`、`0x48E778`、`0x48E7C0`、`0x48E850`、`0x48E898`，保存在 `native-command-profiles.json`，与既有移动配置一起驱动执行器。

## 玩家与 AI 行为

- 新战斗可选全军、全体士兵、前/后/左/右/中军和主将。常用动作保留直接按钮，战术下拉框提供其他命令；主将及含主将的全军选择只允许主将支持的四种命令。
- 士兵十种命令为待命、前进、后退、向下移动、向上移动、分散、中央集中、冲锋、撤退、护卫主将。这里是执行分支对应的 Web 控件，并非原版逐阵菜单外观的完整复刻。
- 后退仍留在战场，主将退到边界后恢复待命；撤退作用于全军且不可取消，避免只撤某个分队后锁住其他部队。旧战中存档保留旧版可分队撤退语义。
- 原版 AI 的“推进”按阵形写指定分队槽；“冲锋”写全部士兵槽，保留主将；“主将出击”只改变主将。评分的 `canAdvance` 改为读取原分队槽，敌方状态判断读取玩家命令标志。
- 军令在下一个单位决策时生效，正在进行的移动段不立即重抽方向。换阵保留已下命令，换将和新一阵建立新命令状态。
- 双方命令槽、标志、共享冲锋目标与部队编号随战中存档保存。当前目标尸体即使已停止显示，也保留到下次命令决策切换目标，防止目标游标丢失。
- 无 `nativeCommands` 的旧档继续旧适配器，不回填新命令或改变旧档随机流程。显式选旧阵形别名也沿用兼容路径。推断补兵技能的新兵继承对应命令，但补兵分队分配本身仍未按原脚本核实。

## 验证

- 核心全量：29 文件、9,602 项通过，包含 1,080 组原程序样本及 10 个军令生命周期测试。
- Chromium：35 场景通过；新增桌面、手机的键盘选队/下令检查，保存后恢复分队军令值。最终边界修复后重跑 4 个相关场景，全部通过。
- 类型检查与生产构建通过；固定服务端口仍为 25369。
- 人工检查 `screenshots/native-commands-1440.png`、`screenshots/native-commands-390.png`。界面控件可用、无横向溢出，显示布局仍为 Web 适配。
- 最终日志在 `docs/evidence/commands/`。旧存档测试显式去掉新命令状态，保留对旧行为的断言；新战斗的全军撤退有独立测试。

## 未完成的一比一边界

本轮核实命令路由、移动及 AI 分队推进，没有模拟原菜单所有禁用条件、音效/台词阻塞、逐阵专用组合按钮、全部特殊布阵模式，也没有将原五分队菜单按像素还原。命令 7 的共享目标取原创建顺序，但完整对象调度仍是 Web 更新顺序；全局 AI/技能/尸体事件也尚未全部改为源更新粒度。

主将速度/装备、全部技能脚本及军师效果的原版执行、电脑之间的战斗结算、完整战略状态和年度人才决策仍需核实。画面坐标与逻辑格仍分离，满编单位的视觉重叠与镜头投影仍需改进。函数样本一致不能证明同一 SAV 整局回放一致。
