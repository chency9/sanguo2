## 如何判定完成

每项必须依次具备：原版依据 → 实际代码路径 → 原机或原解释器对照 → 游戏内可操作 → 存读档继续一致。涉及画面的项目还必须有同状态的原版截图或录像。文档、资源提取、界面占位和通用替代效果均不算完成。

以下93项使用三种状态：**待补**表示没有完整可用路径；**部分**表示已有实现但仍有缺口；**待验**表示已有原码实现，但尚未完成完整流程对照。没有依据的细节登记为问题，不擅自填写数值。当前没有整模块获得完整一比一验收。
