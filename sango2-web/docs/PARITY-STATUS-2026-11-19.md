## 完整一比一的验收条件

1. 同一版本原客户端与 Web 使用可对应的存档、随机状态和输入序列，逐源更新比较关键对象、事件和 RNG；记录第一处分歧。
2. 原战略和战术决策的输入、候选顺序、权重、随机调用及执行后的状态连续对应，不能只复验纯函数。
3. 所有 110 技能、军师效果、装备、成长、人才、战后与年度流程均有真实路径，清除上述通用暂定结果。
4. 原 640×480 的菜单、地图、布阵、施法、命中、死亡、轮换和结局建立实际截图/录制基线；与 Web 同状态比较，再验证宽屏和触摸扩展。
