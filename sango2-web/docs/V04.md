# v0.4 全屏战场与原素材 HUD

## 最终实现

战斗挂载时隐藏战略顶栏、地图和底部状态栏。战场画布覆盖整个窗口，控制区和下方 HUD 由网格布局分配空间。渲染器读取可用交战区域，以相同的 X/Y 比例绘制人物和单位，背景等比覆盖视口；手机竖屏不会把士兵、战马拉长。页面使用 100dvh 和安全区域边距。

原生 Fullscreen API 的目标是包含战斗和存档对话框的应用根节点。因此，进入原生全屏后存档对话框仍可操作。主动退出全屏保留战斗状态，离开战场会退出本应用占用的原生全屏；API 不支持时按钮禁用，调用被拒绝时显示可关闭提示，继续窗口内战斗，不把此错误当成资源载入失败。

## 原素材依据

- WAR0D.SHP：640×136 双侧肖像槽、金边、底纹、剑槽和中央计时槽。
- WAR09.SHP / WAR0B.SHP：左右两侧剑形体力图，按当前 HP 裁切显示。
- WAR0A.SHP / WAR0C.SHP：窄屏适配使用的剑槽背景。
- 两侧肖像为原 FACE 素材；场景继续采用原 BG/MG/FG/FLOOR 素材。
- 转换器可重复导出全部 25 张 WAR 系列 UI 资源并记录来源指纹。此次资源重建得到 442 张独立导出图片，另含 188 个战场对象和 4,376 张动画源帧。

参照图见 screenshots/source-war-panels.png。HUD 槽位依据素材像素位置实现；没有可执行原版截屏作为逐像素验收基线，所以不能把这次改动称为百分之百 UI 还原。工具栏、命令交互、字体、技能栏、选将面板内容及原运行时的坐标/比例仍待对照。

## 使用

从「演武场」或敌城交战进入全窗口战场，点击「全屏战场」可隐藏浏览器外框。双将演武先在选将对话框中确认，然后布阵、开战；「两军名册」按需展开并暂停战斗。音乐可在战斗内切换，演武场禁用战中存档按钮。

窄屏模式是网页适配，不冒充原版支持竖屏。桌面保留源面板比例，竖屏优先显示可读的武将名、体力、技力、兵种和兵力。为保持所有单位可见，竖屏人物尺寸小于横屏。

## 验证

31 项核心测试和 17 项 Chromium E2E 通过，类型检查和生产构建通过。六种视口覆盖 1920×1080、1440×900、1024×768、844×390、390×844、320×568。检查画布与视口尺寸、人物 X/Y 缩放一致、所有可见按钮中心不被遮挡、原生全屏内存档及拒绝全屏后的继续战斗。另回归轮战、暂停、刷新读档、地图与战役流程。
