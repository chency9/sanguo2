# 城池归属辨识与原版倒计时

开发、预览和 Playwright 入口统一固定为 `http://127.0.0.1:25369/`，启用 strictPort，端口占用时不自动换号。

## 城池归属修复

用户截图中的问题可复现：所有城池采用同一种金色素材，仅靠很小的旗色表达势力；无主城没有独立文字与形状，列表也未显示归属。数据并未缺失，问题出在呈现层。

- 我方：双圈底标、金边标签、“我·势力名”。
- 他方：势力色底标、旗帜和完整势力名。
- 空城：淡灰城图、菱形、虚线标签“空城”，不挂势力旗。“空城”在此明确指无主，不把有势力但零驻军的城市误标为无主。
- 列表补充我方/他方/空城与势力名，地图增加可展开的势力图例和实时城数。
- 地图标签使用原生按钮，可用键盘选择。与画布共用相机变换，缩放和拖动保持位置一致；检测到拖动时不误点选。
- 标签尝试在城池下、上、右、左避让；移位时画连接线。缩略图过密时省略冲突标签，但保留可点击城标；选中城市优先显示，放大后展开更多标签。所有城市仍可从“天下诸城”列表访问。
- 归属统一读取 session 当前数据，攻占、读档和剧本切换都更新，不使用初始剧本 ownerId 冒充实时归属。

这是针对可读性的 Web 改进，不声称这些文字标签和避让行为与原客户端逐像素一致。

回归先在旧版失败（地图缺少“洛陽 · 我方 · 何進”标识），修改后验证三类归属、键盘选城、攻占安定及读档更新。手机测试验证已显示标签不相交、放大显示更多标签。最终[桌面截图](screenshots/map-ownership-desktop.png)已人工检查。

## 新补出的计时证据

先前 IDA 批量导出仅遍历已识别函数，遗漏了 `0x444459` 战斗分派代码。此次在分析数据库中只读解码该区间，没有修改原游戏。脚本和原始结果保存在：

- [补导出脚本](../../web-port-research/evidence/ida/export_timer.py)
- [计时分派汇编与交叉引用](../../web-port-research/evidence/ida/timer-dispatch.json)

EXE SHA-256：`1098558aaea96ae552753df786a8d3910df08fda11c8219dfa133ca001d8e419`。

| 证据 | 结果 |
|---|---|
| `0x444614` | 战斗初始化把 `0x4AC35C` 写为 `0x2E68`，即 11880 |
| `0x44452F` → `0x44411B` | 正常战斗更新递减计数，零时置结束标志；暂停/脚本状态走其他分支 |
| `0x440DC3` | 整数除以 120，截断到 0..99，使用 FONTS05 显示中文数字 |
| `0x450410` | Windows GetTickCount 转为每秒 1024 单位 |
| `0x4685C0`、`0x4685F0` | 正常调度阈值 17 单位；更新后减 17，积压最多保留 272 |
| `0x43031D` | 每轮执行更新，再增加源帧计数；默认重复次数 1，可由启动参数覆盖 |
| EXE 数据 `0x4A2C5C=3`、`0x4A64F8=0` | 默认启用该限速路径，未设置重复更新覆盖 |
| SANGO.INI FONTS05 | TNUM 字图 19×19；ASCII 48..58 对应零至十，58 不是冒号画面 |

新战斗使用 11880 源更新的时限，每三个源更新组成一个 Web 模拟步，步长由 0.05 秒改为 `51/1024` 秒。默认正常速度理论全程约 197.23 秒；界面显示原版“九十九”倒计时，**不把这个计数标为秒**。首步后按原生整数除法显示九十八。

新增 `timing: native-99` 随战斗保存并跨阵保留。缺字段的旧战中存档仍按原来的 20 Hz、3600 步结束，不延长已有局。旧存档的 HUD 同样用剩余源更新的计数表示，其时限并非新的 99 计数。

新增 11 张 TNUM 原字图。零至十、十一至十九、整十、两位数按原函数指定 x=308/299/289，y=355 排列；窄屏保持适配。可读数字留在 timer 语义中，装饰字图使用空 alt。

## 验证与限制

56 项 Vitest、23 项 Chromium E2E 全量通过，TypeScript 与生产构建通过。核心新增测试覆盖字形边界、最后一步结束、保存恢复和旧时钟兼容。浏览器检查真实字图加载、暂停保存恢复、城池归属、6 种战场视口及 24 组地形。服务 25369 返回 HTTP 200。

尚未完成原客户端动态逐帧对照。三次源更新仍合并为一个 Web 战斗步，原版暂停、施法冻结、死亡慢动作和脚本调度尚未完整重建；伤害、阵形、兵种相克、AI、全部技能和命令面板也不等同原版。此次计时证据不能证明整场战斗达到一比一。

Modern Web Guidance 的 accessibility 建议已应用：“Prefer HTML elements and attributes to ARIA”“Do apply `alt=""` to decorative visuals”。城池标签采用原生按钮，并同时用文字、形状和颜色表达归属。
