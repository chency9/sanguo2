# v0.3 逐将交锋与原始动作映射

本轮把战斗状态从“一场战斗只有一名主将”改成了可保存的逐将轮战模型。

- 出征军队为每名武将保存独立兵力；调兵界面可逐将配兵，并校验配兵总和。
- 战斗进入 `intermission` 时，当前败退武将被标记退阵，双方仍有可战武将即可选择下一阵；`withdraw` 明确结束整场战斗。
- 每名武将的 HP、MP、余兵和退阵状态跨阵保留，战斗最终结算时写回战略层；守军余部会撤入友城。
- 战斗存档保存轮次、名册、历史、单位、动作、随机数和攻击进度。`upgradeBattle` 将 v1 单将战斗提升为一名成员的 v2 状态，不重置时钟或单位。
- 转换器读取原始 `TYPE`、`WEAPONTYPE`、`WEAPONOBJECT`、坐骑对象和兵种对象。188 个对象、4,376 张帧被打包为 2048 分页，客户端按当前双方对象加载页面。
- `@%OM_ATTACK` 的来源 tick 同时用于战斗命中和画面动作；源文件的 60 Hz 到 Web 20 Hz 换算仍需原版运行时校验。

已验证：31 项 Vitest 核心测试、9 项 Chromium E2E、TypeScript 检查和生产构建全部通过。浏览器测试覆盖双将演武进入下一阵、地图缩放、战中刷新读档和移动端布局。

这仍不是一比一完成：原版可执行文件尚未运行比对，伤害公式、战场时钟、阵形坐标、人物 TYPE 的全部特殊值、兵种相克、武将技/军师技、敌方战略 AI、俘虏、事件和结局仍需要继续逆向和验证。
