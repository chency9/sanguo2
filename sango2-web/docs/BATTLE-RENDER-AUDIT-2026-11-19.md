# 战场渲染与存档边界核查（2026-11-19）

本轮从前一轮特效绑定和原版投影实现继续核查，修复了实际可复现的高度、视距和存档生命周期问题。以下结果不代表整体一比一验收。

## 核查结果和修复

| 问题 | 修复与验证 |
|---|---|
| 投射技能、范围技能、状态技能的命中闪光统一使用 24 高度 | 创建事件时分别保存 `targetZ` 为 48、24、36；普通攻击保留 25/23 的两端高度。纯函数通过同一份逻辑坐标定位，绘图不改战斗快照 |
| 补兵入口闪光通过最近单位推算位置 | 保存入口的固定点；移动其他单位不再带动入口闪光 |
| 尸体到清理时间，而特效仍引用其 ID | 存活特效引用的单位记录保留至特效结束；验证中途 JSON 保存、读取、继续与未读取分支完全一致 |
| 近远视距只缩放人物、投射物和特效 | 原生场景在 Canvas 视口变换中统一缩放一次，地面、景色、单位和特效共享变换；拖动和 HUD 继续使用原有接口 |
| 远景地面被横向拉宽、纹理环绕不完整 | 按地面投影比例和可见宽度采样，跨多个纹理周期连续铺满；扫描带按相机 Y 和视口底边缓存 |
| 宽屏全景被拉伸，远景边缘成为色条 | 中央原 640 像素使用原版裁切，只有素材外的宽屏区域采用镜像延展；额外天空使用载入时采样的源素材顶部平均色，避免竖向条纹 |
| 新征程仍显示“敌方战略 AI 尚待实现” | 删除过时的开发说明，替换为游戏目标文案 |

## 原版证据和适配边界

保留 `0x441C9A`、`0x43A562`、`0x441E07`、`0x43FF4E` 的既有原码样本以及 `0x4419A0` 的全景裁切公式。本轮没有修改这些已对照的函数。坐标投影继续由 `native-projection.test.ts` 的原机器码样本验证。

特效 48/24/36/25/23 高度来自现有 Web 技能和攻击事件的不同位置偏移，属于恢复各事件原有区分，不能作为原始技能 VM 精确坐标的证据。远近视距、素材外的镜像延展、额外天空和地面采样也属于 Web 视口适配；原版 640 像素区域继续保留源图比例和裁切。

旧存档缺少新增字段时仍按旧字段渲染，不强制迁移、不增加随机数消耗。只有新事件保存额外高度和固定入口位置。原始全局对象调度、完整技能 VM、电脑双方完整实战及连续战役决策回放仍需继续核查。
