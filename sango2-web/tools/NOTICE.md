# Content conversion

The PAK and SHP format descriptions are based on `../sango2-english-patch/tools/pak.py` and `shp.py`, distributed under the MIT license by Sango2 English patch contributors (2026). A copy of the original license is included in `LICENSE-sango2-english-patch.txt` alongside this file.

The converter reads the supplied game data; it does not execute the game. Generated art, music and data remain local and are ignored by Git. The MIT license for the patch tools does not license the game's artwork or music.
