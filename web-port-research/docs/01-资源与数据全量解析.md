世界地图 `SHAPE\MAP\CHINAMAP.SHP` 实际为 **1280×960**。原英文补丁自动化采用 640×480 窗口坐标，但地图纹理尺寸不能据此缩成 640×480。城池坐标与道路折点在地图坐标系中，浏览器需要区分世界坐标、相机坐标和页面 CSS 像素。

![实际地图与配置道路](../previews/world-map-routes.png)

上图使用真实地图、60 个 CITY.POS 与 116 条 PATH.POINT 绘制，不代表已确认所有道路都可通行。五个剧本把全部路径暂按无向边处理时均只有一个连通分量；`LENGTH=30000` 等特殊值仍需验证，不能直接作为普通可行道路参与最短路。

![武将部件样本](../previews/sheet-SHAPE-MAJOR.png)

SHP 头的两个尾随坐标值可以超出图像尺寸，例如某主将部件高度 99 而字段值为 141。它们是组合定位的重要候选字段，必须原样保存并验证含义，不能把图像裁成紧边后统一以中心为锚点。镜像、身体/头部/武器/坐骑的偏移、阴影和深度排序均属于下一阶段的真实画面对照项。

所有 SHP 外接矩形合计 **98,445,175 像素**。若不裁剪、不去重，全部展开为 RGBA8，仅基础 SHP 的像素就约 **375.54 MiB**，还没有纹理填充、mipmap、音频、CPU 副本和可选头像。由此确定按场景/单位/技能分包加载，不能把所有素材塞进一张图集或开局全上传 GPU。

### 动画定义

`THINGS.INI` 包含 **621 个 OBJECT 段、620 个唯一 Sequence、4,026 个动作字段**，已保留来源行和逐项 token 分类，见 [对象表](../data/object-definitions.csv)、[动作记录](../data/animation-actions.json)。

- 35,269 次明确图片引用可解析，对应唯一已找到图片 9,927 个。
- 263 次 `$...` 音效引用可找到对应 WAV。
- 1,109 次 `@...` 事件标记、6,848 次 `#...` 数值标记、15 次 `!...` 脚本回调已保留。
- 15 次脚本回调、9 个唯一数字 ID 全部能映射到当前 SO 入口，详见脚本报告。
- 8 个未找到的图片名全部来自 `OBJECT Sequence=99 / 測試用物件` 的 `M1R10001`—`M1R10008`。它们不是“解码失败”，是原配置中的未解析引用；是否运行可达仍未证明。
- 17 个其他 token 包括模板说明及未知标记，不能静默删掉。`Life=1200/2400` 是独立数值字段，已避免误解析为图片名。
- `Sequence=17021` 重复两次，但两个段全部字段相同。允许显式去重并保留双来源；不同内容同 ID 仍应报冲突。

52 个 `ForceSoldierObjectProcess` 对象是 **13 兵种 × 普通/红军/骑兵/骑兵红军变体**；它们不等于 52 个可选兵种。120 个主将处理器对象、348 个技能物件处理器对象也不能直接当作武将或技能数量。

| COMBINE.INI | 1 个 SHAPE 段、4 次 SHAPE 子项，测试组合图 | 已读取；不能仅凭该文件认定真实主将组合系统已恢复 |

全部原始字段保存在 [config-records.json](../data/config-records.json)，字段/记录结构在 [config-schema.json](../data/config-schema.json)，便于查询的内容表在 [game-catalog.json](../data/game-catalog.json)。其中 `units`、`formations` 数组为空，只表示 SANGO.INI 没有这两种配置段；兵种来自 THINGS、人物能力和宝典，阵形仍有引擎布局规则，不能解释为游戏没有兵种/阵形。

所有配置严格 CP950 解码成功，中文语义正常。包内外部说明使用 GB 系编码，不能对所有文件统一硬套 UTF-8/GBK。游戏画面所用简体字形包也不意味着配置内部汉字变成简体。Web 输出统一 UTF-8，原始字节、源名、语言显示名分别保存。

通用 INI 解析完整保留段、字段、原始值和行号。THINGS 只有 3 行不含等号的对象范围说明，单独存为 `unparsed_lines`；未丢弃。百分号宏、十六进制、逗号/空格列表、`#FLAGS`、同名字段都需专门语义转换，不执行字符串表达式 `eval()`。
